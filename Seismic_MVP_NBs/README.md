# Seismic

Instructional Jupyter notebooks for working with seismic data and scientific workflows in GeoLab.

## Notebooks

1. 01-discover-retrieve-seismic-data.ipynb: Discover and retrieve seismic data.
2. 02-inspect-prepare-seismic-data.ipynb: Inspect and prepare seismic data for analysis.
3. 03-running-a-scientific-workflow.ipynb: Use prepared seismic data to run and evaluate a scientific workflow.

The notebooks are intended to be completed in order, with later notebooks building on selections and outputs from earlier notebooks.
