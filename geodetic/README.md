# Geodesy

Instructional Jupyter notebooks for working with geodetic data and scientific workflows in GeoLab.

## Notebooks

1. NB1-access-gnss-via-SDK.ipynb: Instantiate the EarthScope SDK and retrieve GNSS observations for any station.
2. NB2-instantaneous-PPP-positions.ipynb: Retrieve Instantaneous (high-rate PPP stream) GNSS positions and produce visualizations of the position streams and the displacement derived from them.
3. NB3-inspect-prepare-visualize-observations.ipynb: Retrieve GNSS observations for multiple stations and inspect the data.
4. NB4-Satellite-Geometry.ipynb: Retrieve GNSS satellite positions and link satellite geometry to the observations recorded at a given station.

The notebooks are intended to be completed in order, with later notebooks building on selections and outputs from earlier notebooks.
